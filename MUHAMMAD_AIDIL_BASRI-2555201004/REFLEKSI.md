# Refleksi P01

## 1. Hal yang saya pelajari

Pada praktikum pertama saya mempelajari cara menyiapkan lingkungan kerja Python, Git, dan GitHub serta membuat struktur repository untuk praktikum PBO.

Saya juga memahami perbedaan antara program prosedural dan program berorientasi objek. Program yang awalnya menggunakan variabel dan fungsi biasa kemudian diubah menjadi class `Mahasiswa` yang memiliki atribut dan method.

## 2. Hal yang paling saya pahami

Saya memahami bahwa program yang dapat berjalan dengan benar belum tentu memenuhi aturan PBO. Struktur program juga perlu diperhatikan, seperti penggunaan class, atribut, method, type annotation, dan pemisahan bagian utama program.

Saya juga memahami fungsi tiga gerbang:
- `periksa_pbo.py` untuk memeriksa aturan/disiplin PBO.
- `mypy` untuk memeriksa tipe.
- `pytest` untuk menguji perilaku program.

## 3. Hal yang masih ingin saya pahami

Saya masih ingin memahami penggunaan `property` dan konsep enkapsulasi dengan lebih mendalam, terutama kapan atribut sebaiknya diakses secara langsung dan kapan menggunakan property.

## 4. Kesimpulan

Praktikum ini membantu saya memahami bahwa pemrograman berorientasi objek bukan hanya tentang membuat program yang menghasilkan output, tetapi juga tentang menyusun data dan perilaku dengan struktur yang sesuai.
