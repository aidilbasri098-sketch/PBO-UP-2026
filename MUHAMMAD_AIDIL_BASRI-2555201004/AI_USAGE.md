Dalam praktikum P03 saya menggunakan ChatGPT sebagai bantuan belajar dan pendamping saat mengerjakan praktikum.

## Bentuk penggunaan

AI digunakan untuk:
- membantu memahami konsep enkapsulasi, property, setter, validasi data, dan objek nilai (*value object*);
- membantu memahami langkah-langkah praktikum P03;
- membantu menyusun dan meninjau implementasi kelas `AlatTani`, `Penyewa`, dan `Alamat`;
- membantu membuat contoh pengujian menggunakan `pytest`, termasuk pengujian terhadap input yang tidak valid;
- membantu memahami hasil pemeriksaan `periksa_pbo.py`, `mypy`, dan `pytest`;
- membantu memahami langkah Git seperti membuat branch, commit, dan push ke GitHub.

Saya menjalankan program dan pengujian di lingkungan praktikum sendiri. Saya juga memeriksa hasilnya dan mempelajari kembali kode serta langkah yang digunakan sebelum memasukkannya ke repository.
