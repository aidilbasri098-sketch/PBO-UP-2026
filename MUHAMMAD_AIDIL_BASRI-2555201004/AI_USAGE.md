# AI Usage

Dalam praktikum P01 saya menggunakan ChatGPT sebagai bantuan belajar dan pendamping saat mengerjakan praktikum.

## Bentuk penggunaan

AI digunakan untuk:
- membantu memahami fungsi Git dan GitHub;
- membantu memahami langkah-langkah praktikum;
- menjelaskan konsep Python dan PBO;
- membantu memahami error yang muncul saat menjalankan perintah;
- membantu memahami hasil pemeriksaan `periksa_pbo.py`, `mypy`, dan `pytest`;
- membantu menyusun penjelasan untuk Lembar Kerja Mahasiswa.

Kode program tetap saya jalankan dan periksa sendiri di lingkungan praktikum. Saya memahami kembali kode dan langkah yang digunakan sebelum memasukkannya ke repository.

## Catatan

AI digunakan sebagai alat bantu pemahaman dan troubleshooting, bukan sebagai pengganti proses praktikum.
